# ФармНавигатор

Веб-сервис поиска лекарств с ИИ-ассистентом Гиги.

## О проекте

ФармНавигатор помогает:
- 🔍 Находить лекарства по симптому или названию
- 💊 Вести личную аптечку с контролем сроков годности
- 🤖 Получать советы от ИИ-провизора Гиги
- 🗺 Находить ближайшие аптеки

## Технологии

- HTML, CSS, JavaScript (фронтенд)
- Node.js, Express (бэкенд)
- SQLite (база данных)
- GigaChat API (ИИ)
